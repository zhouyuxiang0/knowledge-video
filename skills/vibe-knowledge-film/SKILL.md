# 无旁白知识短片

让观众一边读字幕，一边看见解释发生。优先遵从用户已有画风、范围和工具；本包引擎面向 1920×1080、30fps 横屏。其他画幅先调整布局并验证，不静默拉伸。有人声讲解的整套制作流程可使用 `knowledge-video`；本技能不生成演唱或旁白。

## 接手

- 读项目约定、现有文稿、事实来源、分镜和已确认素材。参考片能取得时实际观看，不能只靠标题或旧拆解宣称已对标。
- 明确问题、受众已有知识和观看收获。时间按解释与实际阅读需要决定，不硬套 2–5 分钟、每句字数或某种反转结构。
- 下载依赖与素材、外部上传、付费、发布、删除和 Git 操作遵循当前授权。既有授权内持续推进，不因步骤名称反复索要确认。

## 解释与分镜

先读[视觉解释](references/visualization.md)。给概念找观众认得的对象或能观察的变化，说明其中哪些是机制、哪些是类比；不能把任意光点与连线配上标签就当作解释。数轴、坐标、网络等本身就是对象时可以使用几何图形。

把文稿和分镜一起写：字幕 / 主体 / 动作或状态变化 / 观众此刻新增的理解 / 屏幕文字 / 声音 / 事实依据。问题、命名、结论可以留给文字和静止画面，不按固定比例强配动画。稳定的对象、比例尺和颜色语义帮助跨镜理解。

每条事实保留来源与适用条件，示意与实测分清。文稿独立顺读应回答主问题；装饰、尾卡、音乐和品牌口号都不能补上缺失的推理。

## 制作

1. 按[外观说明](references/worlds.md)选择或调整 B / C，保留项目品牌和必要署名，不默认删除水印。字体、配色和效果服务于信息。
2. 在用户工程里建骨架，技能目录只放可复用工具。路径相对于安装后的本技能目录：

   ```bash
   python scripts/new_film.py <工程目录> --world C
   python engine/render.py <工程目录> --serve
   ```

3. 先做能检验主导风格、最难机制与至少一次切镜的连续样段，不机械限定“开头 30 秒”。实际看过后修正具体问题，再扩展整片；不为凑审查轮数重复改动。
4. 用绝对时间重建状态，随机数固定种子。字幕跟随阅读和动作节奏；没有旁白不等于可以无限延长句子。引擎用法见[引擎参考](references/engine.md)。
5. 先截关键状态、动作中段和切点，再导出样段：

   ```bash
   python engine/render.py <工程目录> --stills 2 5 8
   python engine/render.py <工程目录> --motion 4 7
   python engine/render.py <工程目录> --clip 0 12 sample
   python engine/render.py <工程目录> --det
   ```

6. 全片导出默认单路。只有内存和磁盘余量足够时才增加 `--jobs`，不能把并行路数直接当成速度保证。
7. 在 `film.js` 用 `fr.sfx()` 登记与实际变化对应的事件；也可以使用已有许可的配乐：

   ```bash
   python engine/render.py <工程目录>
   python engine/render.py <工程目录> --events
   python engine/audio.py <工程目录>
   # 或：python engine/audio.py <工程目录> --bgm music.mp3 -8
   ```

   无声画面为 `renders/raw.mp4`，混音成片为 `renders/final.mp4`。事件合成只是音效和氛围，不是 AI 写歌。配乐贴合情绪且不过量，实际听后决定音量与稀疏程度。

## 验收与交付

- 看实际输出：主体可辨、动作因果可理解、关键信息不被辉光或字幕遮挡，切镜保留观众需要追踪的对象。字幕阅读和原速动作都要检查。
- 含人物时分别核对肢体结构、人物自身左右、驱动、支撑、接触和自然度。关键动作先观察合适的真人参考；存疑时先修局部样段。
- 检查全部叙事区段与最后正文到结尾的连续声画。截图、确定性通过、正常解码都不能替代实际观看和听音。
- 记录工程、事实表、文稿/分镜和最终 MP4 版本；分别报告技术检查、连续观看、设备观看与用户接受范围。没有听审能力就保留该缺口，不写成通过。
- 保留已确认输入与上个有效输出，验证新版再替换交付版；清理和发布按用户授权执行。

依赖：Python、Playwright 的 Chromium、NumPy、SciPy、Pillow、ffmpeg。字体用 `python engine/get_fonts.py` 显式下载，`--check` 仅检查。初次可运行[技术演示](examples/smoke/README.md)确认环境；它不代表已完成知识内容或美术验收。
