# 视觉解释

本页整理可复用的方法，不包含参考片的逐句字幕或复刻画面。

## 找对象和变化

问清这个概念是可见物体、过程、数量、规则，还是人的判断。选择能让受众认出的对象：保留决定行为的结构，删除无关细节。看不见的机制可用剖面、尺度变化或类比，明确对应关系和失效边界。

| 要解释的内容 | 可采用的方式 | 需要核对 |
|---|---|---|
| 结构决定作用 | 展示整体，再进入关键结构 | 放大前后是同一对象，比例变化说得清 |
| 条件改变结果 | 同一装置改变一个条件 | 比较条件可比，画面没有暗改其他变量 |
| 积累、概率或数量 | 计数、重复试验、分布 | 数字来自实际计算，固定种子，可重复 |
| 顺序和反馈 | 状态转换与返回的影响 | 先后、驱动、延迟可观察，箭头不冒充机制 |
| 不可见作用 | 对照、剖面或明确的示意 | 观众能区分直接观察与解释模型 |
| 提问、命名、结论 | 文字或暂停当前装置 | 留足阅读时间，不为每句额外造景 |

点、线、圆不是禁用元素；问题在于它们是否具有清楚含义。解释网络时节点与连线就是对象；解释动物行为时，用任意圆点平移替代行为往往丢失关键线索。

## 一句字幕对应什么

对每镜回答：主体是什么、具体变了什么、观众因此明白了什么。字幕说发生了某个动作，画面要给出其过程与结果；仅切颜色或换标签通常不够。反应、情绪和等待也可承担叙事，但要有明确作用。

同一装置撑住连续推理，镜头只在需要新信息时推进。全景交代关系，近景让关键变化可见；近景必须真的增加信息。保持身份线索、尺度、颜色含义和方向，避免切镜后让观众重新猜对象。

## 连续样段检查

先选主导风格与难点的交集，包含进入、变化、结果和切镜。检查主体占比、文字安全区、阅读时间、遮挡、接触、相机运动中段及退出。小图或静帧可定位问题，不能证明原速观看自然。

去掉字幕检查画面是否传达了应由画面承担的变化；只读字幕检查解释是否完整。两者不必分别讲完全部内容，但合起来必须兑现主问题，不能互相掩盖缺失。

## 常见返修

- 辉光吞掉轮廓：先降低亮度与 bloom，实心主体画在不参与辉光的底层，再看最终编码。
- 切镜没有新增理解：保留当前装置，改变条件或景别；不要为“丰富”加入无关镜头。
- 相机移动时看不清：追踪整个轮廓和关键标签，不只检查中心点或起终帧。
- 模拟无法乱序 seek：将初值与随机过程固定，预计算或按时间直接求值，不依赖上一帧。
- 画面和结论不一致：回到事实依据与条件，先修解释，再处理视觉风格。
