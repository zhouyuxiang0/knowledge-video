# 内容与成片验收

检查为当前任务服务，可合并进既有分镜和 QA；不要求固定表格数量。每项结论指向实际材料，记录检查方式与尚未验证部分。

## 文案定稿前

整篇正式配音和批量分镜前，结合 [文案推进与科学边界](notes.md)检查整篇实际稿件。审稿可以写在现有文稿或 QA 中，但须绑定稿件身份，并给出具体句段和判断依据；不靠自动填“通过”或统计问句、字数来证明内容成立。依赖声音表演的段落可以先做小范围试读，帮助共同修改措辞与讲述方式；试读成功不等于整稿定稿或整片听审通过。

引用问题句须逐字核对，补出的上下文或改写句另外标明；不能用审查者润色后的句子证明原稿自然。编辑判断除了事实与逻辑，还要检查读者需要自行补多少语境，不能把“我能解释它”直接判成“表达清楚”。解释一个笑话的创作意图也不等于证明它有效；检查前文是否真的给出了所需铺垫，以及该句带来了什么可辨认的变化或反差，不能仅凭使用某种修辞判为通过。

用户限定“前三秒”等理解窗口时，先只给相应的开头文字做初读，记录理解、自然追问和所需前提，再与实际选题对照。窗口长度只控制可见上下文，不是易懂评分；不拿对象可辨、整段最终可解释、配音时长或成片检查证明开头已成立。验证通用方法时，让未参与规则修改的写稿者使用更新后的skill生成不同题材的新稿，再独立审查；测试不只改本期一句，也不只分类预制句子。混入对象清楚但暗含陌生前提的反例，以及正常问句、陌生事实的直接揭晓、明确故事处境与可保留悬念的对照。预先记录判断依据，保留首版、误放行和不必要的改写，检查有没有被规则强行统一成一种开场。

按三种阅读目的检查，不强求三个审查者或三份文件：

1. **先按观众获得信息的顺序检查。** 第一遍只读实际文案，暂不借用选题卡、研究、分镜或旧审稿结论。先单独看开场首次抛出情境或冲突的原句，不看后文，记录自然理解、第一反应会追问什么、哪些信息必须先知道才能接住这一问。能说出对象或复述问题，不代表观众已经知道问题暗含的事实。对必要前提，指出它来自目标观众的普通经验、此前原文的明确介绍，还是作者未交代的知识；需要靠研究背景才知道的前提不能列作常识。若自然追问仍是“真的有这回事？”或“这是什么？”，而稿件已经要求解释其原因、用途或反常之处，记录具体缺项并修复。陌生事实若已被清楚地作为新发现呈现，原因仍可留待后文，不因内容新奇就判失败。

   “观众已知”一栏不能从待审问句的隐含命题倒填。审查者自己接受了这个命题、马上能追问原因，不是受众拥有该前提的证据；仍须指出它来自普通经验，或哪一句已把它作为新发现、现象、明确假设呈现。信息只藏在因果提问的条件里时，按缺少交代处理；正常的日常现象问句、直接揭晓事实的问句、猜答案和故事悬念不因此改写。

   记录初读后再提供全文，继续按出现顺序核查：此前理解是否被迫改成另一时代、对象或事件；新术语、比较与关键结论各凭此前哪些信息成立。不能用后文或作者意图倒补前面的空缺。观众可以暂时不知道答案、人物身份或事情结果，不要求开头罗列背景或讲完机制。可引用确已设计好的同时画面承载信息，但须明确何时可见并在样段中验证；纯文案测试不借尚未提供的画面。发现会影响理解的缺项后，修复并复读前后文，才进入整篇正式配音。随后对照资料核实事实，并检查开头与中段实际让人惊讶、想猜、想笑或期待后果的句段；删去或交换某段会损失什么理解、笑点、情绪或期待？事实边界是否在观众形成判断时已经出现？
2. **追踪语境与主张。** 核对关键句中的人物、时代、群体、说话者与“你”各指谁；历史、影视、示意与现实观众是否被混接？检查精简、对偶或反转句中的词在此刻是否有多个合理解释，尤其是否把本片要区分的对象、特征和内容混叫成同一个词；有歧义就补出具体名称或关系，再连读上下文，不能借后文或画面替当前措辞放行。语境已明确的省略仍可保留。对拟人句，查明前文实际建立了什么角色或类比，意图、对话、协商等社会行为帮助了哪一步理解；没有铺垫、只是把物体说得像人，或需要作者事后解释才成立，就改为直接表达。还原修辞后事实正确，不足以证明措辞自然。用实际句子说明，不能仅说“已检查指代”。
3. **核对承诺与收束。** 审查者先读实际全文，独立写出“开头要解决什么、读到最后实际得到什么答案、此刻还在期待哪一句”，再看作者的解释或方案说明。复读正文末段到最后一句，引用真正完成回答的句子及其承接依据；不能只提供改写后的最后几句，或先告诉审查者“这是永久与临时的对比”等预期结论。若只能指出物体最后在哪里、工序已做完或一句工整的对偶，却还需作者补上它怎样回答主问题，则收束不通过。状态、回扣、幽默或简短落点本身不禁用，按全文是否已经把回答交到观众手里判断；不强加总结句、升华或固定结束语。观众仍在等关键关系、结果或后半句话时，先补正文或改末段，再配音。

发现实质问题先修稿并复读受影响的前后文，才能开始整篇正式配音与批量分镜。用户否定的稿件标为失败，旧审核结果不沿用；同时回查旧审核为何放行，不能原样重复“有反转、有笑点”的评语。需要参考校准时，按[实际参考对照](notes.md#用实际参考校准写法)定位差距，并以新稿的具体改动回应。事实核对、编辑判断、实际听审和受众反馈分别记录；稿件通过只支持进入制作，不能证明观众已经听懂或会提高播放。

## 内容和视觉必须表达同一件事

在分镜中记录：镜头范围 → 对应话语 → 预期理解或观看回报 → 画面承担的信息、反应或笑点 → 事实/类比/虚构性质 → 来源或依据；同时简记表现形式及选择理由。逐镜检查主画面，不只检查字幕；不因反应镜头没有新增知识就判它无效。

先检查整片的视觉选择是否符合用户方向：局部适用的3D是否因复用模板而铺满生活场景、对话和研究图解？镜头改成更合适的插画或平面动画后，理解与表演是否反而更清楚？几何、接触和渲染检查通过不能代替这一判断；样段应体现计划中的主导风格和不同表现形式的衔接。

常见需要分开的概念：

| 话语所指 | 画面需保留的区别 |
|---|---|
| 重复与新材料 | 两类身份及首次/后续接触顺序，而不只是反复出现同一纸张 |
| 某人作答与群体平均 | 个体操作只能说明流程；群体结果另有明确表达 |
| 测量指标与被衡量的概念 | 若几个指标共同表征一个概念，画清组合关系；不把指标和概念并列为独立新增结果，也不擅自画成确定的因果顺序 |
| 影响仍增加，但增幅减小 | 展示同一指标的增量变化，不能用“处理更快”的动画替代 |
| 已有相关知识与尚不了解 | 有知识但未调用、缺少相关知识、没有看过这句话是不同状态 |
| 准确性判断与趣味性判断 | 保留分组任务，后续结果沿用身份和适用条件 |
| 多个报道与独立证据 | 显示材料来源关系；同源转载不能画成多份独立验证 |
| 核查与核查结果 | 打开资料不代表已证实；未找到证据也不代表已证伪 |

这些例子是判断方法，不要求每个主题包含这些镜头。新主题同样识别容易被图形偷换的概念。

没有原始数据时可用明确标注的定性趋势；不得伪造坐标数值、人数、效应量、显著性或精确阈值。图形位移用于说明关系时，要写清“趋势示意/非实测数值”，且形状本身不得暗示来源不支持的关系。

面向观众的标注应解释证据含义与适用范围，例如“群体平均，不代表每个人”。“尚未核对效果大小”等制作状态或验收备注留在制作记录；需要披露的不确定性，改写成与当前结论有关的限制。

研究中的低频事件不能简化成从未发生。演示其中一段时标清片段性质；分组、干预和结果限定要在相应叙述期间出现，并留出稳定阅读时间，不能在切镜前才闪出。

近景需要揭示观众看得见的新信息：哪一行、哪个条件、哪种差别、哪个物理变化。用横线假书页配“核对原文”字幕，通常不足以解释究竟核对什么。相反，开头只是尚未判断的情境，就不能提前借用后半段已经呈现结论的图形。

## 参考作品与代表性样段

含人物的插画与独立封面须按原尺寸逐条追踪肩—肘—腕—手，以人物自身左右核对掌背、拇指根部和四指排列，再看肢体数量、袖口归属、遮挡和持物关系；两只手都存在不代表一左一右。双手同时托脸、持物或交叉时，不能漏掉混接的袖子或多余手臂。返修后重看加上品牌与文字的最终文件，横竖两版分别检查，再核对平台裁切预览。

记录少量具有决定意义的实际参考片段：时间点、主体在做什么、注意力落在哪、镜头为何切换、声音怎样帮助理解。不要用参考的分辨率、时长或截图数量代替观感分析。

样段应覆盖本片最可能失败的环节，例如持物到放下、托腮、写字、翻页后检查资料、复杂比较结果；包含实际文字、景别、声音或明确的待补声音状态。先看动作和解释是否成立，再做整片复制。若用户已确认样段，不重复索要相同批准；后续发现实质缺陷仍需修正。

含人物时执行[人物动作放行](character-motion.md#人物动作放行)，审查者从实际画面判断，不以旧报告的“通过”为前提。同侧双手、肘部翻折、腕口断裂、多肢、错误遮挡、物体脱手漂移等属于阻断缺陷。结构与原速自然度都通过前，只允许局部修复短样；技术报告通过、附上待验收声明或改称候选整片都不能绕过。

比较时同时问：

- 主体有明确意图、视线和承重吗？动作是否改变对象或理解？
- 场景、近景和图解各承担什么信息？是否一套姿势反复替代不同含义？
- 文案是否完整展开，且有停顿可供理解？是否靠重复拖长？
- 参考中的表现力来自哪里，本片有没有相应实现？记录具体差距，别只判“好看”。

## 批量生产与修改影响

- 先枚举共享组件的全部调用及变体。相同 `scene` 或 `variant` 名称不保证同一语义，检查每个调用的章、目的、条件、文字与继承的来源标签；真实研究结果不能沿用生活场景的“虚构示意”。在相应结果画面实际出现时复核，不只检查分镜备注。
- 新的非平凡动画逻辑用最小有效自检覆盖接触点、关节范围、绘制栈和边界状态；此类检查仅证明对应不变量。
- 对每类动作看进入、接触、峰值、释放、停稳。看连续短片，再用高密度抽帧定位问题。快速事件提高采样密度；不要拿稀疏四格图排除中间穿帮。
- 需要对读的文字要有足够的同时无遮挡时间。记录翻页或手部遮挡占用了多少阅读窗口，不能因某一帧可读就判整段通过；优先调整动作占比与停稳时间，并保留已确认音轨的同步锚点。
- 同一行为跨镜头共享全局进度；切镜处检查前后帧及视觉尺度变化。相邻不同场景也要看空间和信息的交接。切换互斥叙事状态时完整退出旧文字与图层，并检查边界两侧及新镜头稳定帧，不能只确认新对象已出现。
- 场景判定保留绝对秒数，夹取范围时不先除以总时长再乘回；浮点往返可能把准确切点变成边界前一瞬。用实际段落起点断言已进入新场景，再核对切点前后编码帧，避免旧段多停一帧。
- 关键结果依赖接触近景时，保留到动作落定并有可辨认的短留，再切远景；几何已经接触不等于观众看清了结果。
- 流程图的当前步骤高亮随实际讲解推进；总览可以提前保留，但不能旁白已讲到后一步，视觉强调仍停在第一步。逐个核对高亮切点，而不只看流程文字齐全。
- 动态标签区分状态和方向：“距离较近”描述位置，“正在靠近”描述运动，不能用位置阈值代替运动方向。检查动作起步、中途和停稳时的文字；解释依赖的主体与参照物也须在对应镜头里实际可见。
- 修改已确认音轨之外的输入时保留音频；核对画面事件和现有音效。出现真实同步冲突再修最小范围，并说明改变了什么。

## 最终文件验收

### 配音读音

- 按 [多音字与读音放行](sound.md#多音字与读音放行) 检查全文各个风险词的实际出现位置，特别是同句异读；目标读音与实际听辨分列，并绑定当前音频摘要和时码。专名、年份、单位及缩写同样按语境核读。
- 错读或待听辨的项不放行。文本、ASR、强制对齐、波形、响度和用户对音色的认可都不能补足字音证据；“整体声音可以”只按其实际确认范围记录。
- 局部纠音后复听完整句与接缝，并检查最终混音中的可辨性和新字幕、画面时码。未改原声仅在身份与范围可验证相同时继承对应结论；不能用旧录音的通过记录覆盖新生成。

### 语速与换音色范围

- 用户要求控制语速时，验证引擎在生成阶段支持的语速或时长参数，并比较实际讲话区间与听感；文件变长或增加尾部静音不等于读得更慢。用户禁止后期拉伸时，长度不合适就重新生成必要语义段。
- 更换合成引擎即使使用同一参考人声，也要验证实际音色、发音和节奏；参考文件相同不能证明输出音色相同。已确认的引擎与参数放在项目共享记录中，不因一轮试听自动推广到所有项目。
- 只换成片音色时先冻结原文稿、画面、字幕、剪辑、音乐、音效及用户要求保留的时长。按完整语义段生成；用户只要求内容对齐时，不额外强求逐句毫秒一致，也不擅自重写或缩短成片。
- 检查短段句尾是否完整、是否硬切有效人声；转写疑似漏字或多读时复核原声和相邻语境，区分识别器在静音处的幻觉与音频本身的缺陷。

### 结尾的实际落点

- 分开记录**文稿收束、原声尾句、整片语境中的声画结束感**。前一项通过不能替后一项通过。收到“突然结束”“还没讲完”时撤销该版结尾放行；先按具体反馈定位层次。不清楚时只问能区分原因的问题。用户明确说文案没结束，就先修理解和回答，不能用延长末帧、补静音、音乐淡出或片尾卡代替。
- 文稿先执行上面的承诺与收束检查，保留失败原句、顺读时仍在期待的内容、新稿怎样完成回答的具体证据。用户已否定的尾句不能因“句意可解释、物理状态已完成、结构有回扣”再次放行；原来仅听过独立尾段的认可也不能覆盖用户随后对全文的否定。
- 实际成片检查窗口从**结尾之前的最后一个正文段落**开始，保留同一版的旁白、配乐、镜头、字幕和转场，看到文件结束。只听新尾句、只看末帧、跳过正文接入处或取静音末尾，都不足以验收收束；不人为指定统一的片尾秒数。
- 在这个连续窗口内分别检查：正文如何进入最终回答、最后一句是否完整且有结束感、关键结果是否看清、动作是否落定、音乐与画面是否结束在合适位置。原速有声检查和密集帧序用于不同判断；工具不能听辨时提供这段**带正文上下文的实际成片**供确认，并记录缺口，不以文字审查或波形代替听感。
- 重新配音、重新剪辑或改变前一段内容后，用新文件重新检查受影响的收束过程。已明确的缺陷修完再复核；未复核的版本不宣称结尾自然或可发布。
- 更新收束规则时，用未见过的不同题材实际写新稿，再让未参与写作和规则修改的审查者只看正文与结尾进行顺读。混入自然简短收尾、主问题已答清的开放结尾，以及仅剩步骤/口号但缺少答案的反例；检查既能拦住提前结束，也不会把所有结尾改成同一种总结模板。规则行为验证与实际成片观感分别报告。

### 画面、声音与文件身份

先绑定最终文件路径、时长和摘要，以及渲染所用文稿、素材、代码和音轨身份。只保留足以定位问题与证明修正的证据，复用现有检查工具。

| 检查 | 能支持的结论 | 不能替代 |
|---|---|---|
| 完整解码、帧数/时码、黑屏/静音检测 | 文件完整性及阈值内异常排查 | 内容、表演、听感 |
| 全片分段/逐秒抽帧实际审阅 | 全片覆盖下的构图与语义抽查 | 中间帧连续性、原速节奏 |
| 高风险动作的连续播放或密集解码序列 | 对应版本、对应段落的动作关系 | 未查看镜头、声音体验 |
| 全部切点检查 | 转场周围的动作和内容衔接 | 整片叙事质量 |
| 原速有声整片观看 | 实际观看条件下的节奏、读速、音画协调 | 手机实机、不同观众体验 |
| 用户试听或观看反馈 | 用户实际确认的维度和版本 | 未确认的其他维度 |

有条件时原速看完有声成片，并按目标观看设备检查字和操作遮挡。工具不能听或播放时，完成可做的检查，记录缺口并给出可播放文件；不要冒充已经听过、原速看过或用户已接受。

逐秒图、动作序列和切点应取自实际编码文件，不能用编辑器截图冒充。切点前后帧须实际位于边界两侧，检查时间转帧的取整误差。不要把生成成功的图片自动标成已读；疑似文字缺损先以原始像素裁剪复核，避免缩放误读。确认问题后修复、重导出受影响范围、再看新文件及相邻切点。

可继承旧证据的条件：明确受影响输入，确认未改镜头的实际编码片段摘要和起止区间相同，且无新的共享输入影响；仅“缓存命中”不足以证明。改动镜头及两侧切点必须重新看。导出后源码再改，旧结论不自动适用于新源码。

交付用一句话说清完成状态，再给成片、简要修正和验收记录。把仍有的艺术表现差距与实际缺陷分开；不凭无报错宣称商业级、与参考相同或绝无问题。

发布包区分完整展示文案与工具输入：工具通过独立话题参数添加话题时，正文文件不再附同一组标签。上传前核对“正文＋话题”与已确认方案一致；提交前再确认真实话题元素的名称、数量和顺序，避免纯文本标签与话题元素重复。

已确认方案包含平台声明时，检查声明弹窗及保存后的主表单文字；自定义单选控件的原生 `checked` 属性可能与实际显示不一致，不能据此独断保存失败。隐藏弹窗可能保留同名文字，回读必须限定到可见的主表单。发布前检查失败时保留原凭据、草稿和未提交证据，恢复同一次上传并重新核对，不重传或重复投稿。
