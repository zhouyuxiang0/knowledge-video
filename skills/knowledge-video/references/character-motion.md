# 角色、道具与连续动作

先看场景构图和角色轮廓，再决定用代码骨架、分层插画、逐帧或现有角色动画。选能完成指定表现的方法；不能为了避开难动作，把用户要求的人物表演全部换成静态卡片。

## 真人动作参考

对承担叙事或机制表达的人物动作，在分镜和关键姿势设计时主动找真人视频参考；尤其是挥旗、持重物、推拉、行走、坐起、拿放和连续操作。已有经实际观察的参考可在目的、视角和持物条件相近时复用，不为每次细小眨眼另建研究任务。不能只凭“动作自然、不奇怪”判断表现已经充分。

- 选动作目的、道具尺度与持握方式、身体朝向、支撑条件和镜头视角相近的片段。现代示范或其他职业的动作可帮助理解人体与道具的运动，但不证明历史人物采用相同仪式、旗语或操作规范；表演性花式动作也不自动适合传令等功能行为。
- 实际取得并查看视频中一个完整行为过程，记录来源、具体时间段、播放速度与观察方式。搜索标题、文字教程和孤立姿势图不能充当已经看过的真人动作。原速用于观察节奏与力度，慢放或密集逐帧用于定位关节、接触与遮挡；只有逐帧条件时明确其范围，不冒称原速观看。
- 拆出预备、启动、主要运动、减速/反转、停稳或回收等实际存在的阶段，观察谁先动、谁随后响应：视线、肩肘腕、胸胯和支撑脚怎样配合，手与道具轨迹怎样变化，布料等柔性部分是否滞后。不要要求所有动作都套齐这些阶段，也不把全身参与理解为每个部位都要摇动。
- 将观察转成当前镜头可读的关键姿势、运动弧线、相位顺序和停顿，再决定骨架、蒙皮或画稿是否能承载。需要更大运动范围或改变掌面/肢体遮挡时先补合适素材；不能只加大原曲线、给各关节叠独立正弦或缩小人物来掩盖表示能力不足。允许为叙事适度提炼，保留受力、接触和动作意图。
- 样段与参考对照时写清具体借鉴及仍有差距：动作是否无需标签即可辨认，发力方向和道具重量是否可感，结果是否有停稳，原速节奏是否服务情境。“无明显变形”“自然”与“表现充分”分别判断；用户只认可其中一项，不自动扩展为整段放行。

## 构图与动作设计

先建立人物自身的左右身份，再制作分层素材。按头颈—躯干—骨盆、两侧肩—肘—腕—手、髋—膝—踝—脚追踪归属、比例与朝向。手须同时看掌背、拇指根部/对掌关系、四指排列和腕部旋转；只数出两只手、只看拇指在画面哪边或引用生成提示词，都不能证明一左一右。遮挡或画法让身份无法判清时，先换可核实的姿势或修原画，不猜测通过。

生成与绑定使用“人物自身左/右”，并另记其画面位置；例如接在人物左肩的素材，不能因位于画面右侧就要求生成右臂。整体镜像会同时改变手的身份、掌背、衣服、道具与作用方向，不能只翻一块手片掩盖接错。原画、分层合成和实际动作峰值都须重查；替换一个部件后，原有结构通过结论失效。

用一句话定义“谁为了什么，对哪个对象做什么，结果怎样”。先隐藏字幕和动作名称，判断画面本身让人认出什么行为，再摆进入、接触、结果三个关键姿势。若只能靠说明把晃动解释成指定动作，先改姿势和运动方式，不进入插值制作。

有功能目的的动作还须明确驱动关节、受力或作用方向，以及手和道具怎样一起改变姿态。接触点贴合不等于运动机制成立：道具转向时，握持手、手腕和相连肢体须有相容的朝向变化；不能只独立缩放或转动道具外观来冒充整个动作。用摇扇给自己降温时，查看扇的位置、扇面朝向和往复扫动是否能向身体送风，而不只确认人物拿着扇子在动。此例不规定所有摇扇都必须用同一个关节或幅度。

- 坐姿要有座位、臀部/大腿关系、膝和脚部支撑；角色不能像站在桌上，腿不能穿过桌面。
- 手机支架、杯底等静置物也要有明确的支撑点；切换房间布局或景别后，检查它与实际桌面、地面的接触，不能只确认手指能碰到道具。
- 先统一镜头视角：房间侧视、桌面斜俯视、纯俯拍各有一致的透视和遮挡。不能只旋转书本而让桌子和手保留另一个视角。
- 轮廓应能读出上臂、前臂和手。合理的夸张比例可以保留，但长度、弯肘方向和左右身份不能随动作无理由突变。手掌朝向须相对前臂检查，不能只固定世界方向；握持改为放松手型时，要复核切换前后数帧，避免手腕突然反折。
- 二维合成必须检查屏幕上实际画出的肢体长度。三维骨长恒定并不能防止丢弃深度后手臂缩没；抽看腕部经过肩线、举过头和松手落臂的中途，比较投影长度、头肩比例和完整轮廓。出现明显缩短时先修骨架表示和关键姿势，不能只改袖口或用接触误差为零关闭问题。
- 手腕目标可达不等于姿势自然。先比较原画绑定姿势与目标姿势的肘角，再确认放松、持物和抬手时的肩—肘—腕轮廓；若手腕插值造成肘部过度外张或弯曲方向翻转，改用已确认的肘部路径或关节角度，再检查接触。空手示意没有固定接触目标时，先试用关节角度设计抬落弧线，避免只把腕点向上拉而逼出二次折角。静止姿势修好后仍须看动作中段与峰值，不以臂长正确关闭问题。
- 关键姿势自然也不能证明中间动作成立。分别检查肢体实际长度变化、弯肘方向和肩线附近的过渡；独立插值关节后拉伸素材可能变成橡皮肢体，每帧选“最外侧”反解分支也可能翻肘。先修轨迹或表示方法，不用圆盘遮接缝。改用完整人物逐姿势画稿时，重新验证切换节奏、身份和道具连续性，不能把画稿完整等同于连续动画通过。
- 视线、肩胸转向、重心和短暂停稳要服务意图。动作少不是自动错误，但同一托腮/滑屏不能包办不同叙事行为。
- 收到“像木偶”的反馈时，先复核动作意图、头身参与、左右先后和收势路线，不只增加补间或调整速度。双手握住同一物体期间共享接触约束，错拍放在接触前与释放后；松手外展、翻掌等姿势可能读成摊手或展示，必须确认它表达的是原定行为。
- 持物与空手收势分别设计。松手后若仍由握点轨迹反求整条手臂，可能让肘部反复经过极度屈曲的位置；必要时在接触解除后连续交接到关节角度轨道，检查肩、上臂、前臂的先后回落。注视对象应先于拿取，聆听等反应应发生在动作结果之后；始终盯着镜头不能靠增加身体摇摆补救。

分层角色需要完整的关节重叠区。整幅姿势图硬裁出的肩袖或上臂，可能带着邻接肢体，也可能缺少旋转后暴露的部分；先在独立躯干上验证袖根、肘和腕的完整摆动范围，再做整段动画。2D 引擎的补间不会补全缺失素材；检查实际轮廓闭合、裁片外露及近景接缝。独立袖片的封口线若像贴在胸口上的圆盖，应修正衣服素材与肩部连接；连续衣服网格也要检查抬臂时的肩线、腋下和袖口，限制权重范围，避免衣服凹口、皮肤穿出或下摆被牵动。

整幅人物网格的手臂权重边界应沿实际肢体和躯干之间的空隙确定，不能只按固定横坐标划分，否则靠近手臂的裤腰或衣摆也会被拖走。手臂收拢后，原本分开的网格区域可能重叠；近景出现断续黑边时检查三角形绘制顺序和区域遮挡，不能把它一律当成素材描边。根据实际前后关系分层或排序，再看放松、靠近和离开的完整过程。

采用游戏引擎时，将角色资源、关节轨道、动作片段与镜头场景分开，让预览和视频导出采样同一动作时间轴。连续皮肤网格仍可能在极端屈肘时翻面或形成尖角，须检查关节外弧、内侧折线和前臂经过袖片时的遮挡。握持到放松需要中间手指姿态，并对齐腕根和掌部尺度；不能只验证两端画稿，或让整个手掌在单帧内换型。

引擎迁移不能代替角色绑定。骨骼路线应明确统一绑定姿势、父子骨链、局部变换、蒙皮权重和关节修正；皮肤与衣服共用骨架，抬手时检查胸肩配合。手写绑定同样需要这些数据和姿势证据，不能只用独立肩肘腕坐标拉伸裁片，再靠衣服外轮廓补偿掩盖问题。二维投影或夸张动作可以改变可见长度，但须有对应姿势、视角和体积设计。先验证放松、前伸、屈肘、抬臂、持物、松手及其连续过渡，再扩展镜头；接触误差与有限顶点检查不能替代这项验收。

## 接触和绘制顺序

先确定道具接触点，再反求手腕/关节位置。握持、指尖点击、捏页、握笔需要不同接触姿势；不能用一根指头代替所有抓握。

接触点必须标在可见的指腹、掌面或握持区域，随同一块皮肤变形导出；随意命名的“grip”坐标不证明画面接触。接触期间由同一动作状态驱动手和道具，不能分别用目标姿势与固定偏移编两条轨迹。推物时物体底部留在支撑面，手贴接触面；松手后先解除接触，物体保持已落定位置，空手再退出。道具前后层级须分别检查：整层放在人物后会被袖子吞掉，整层放在人物前也可能盖住本应压在上面的手指。

只让一个组件拥有每只可见手。角色函数已画手，场景层再次画手，会长出双手或断开的手指。需要道具夹在手和前臂之间时，把层级明确拆开。

演示输入或选项操作时，用同一个步骤索引驱动指尖、按键、屏幕结果和音效。检查示例中每个字符都有对应按键，尤其是0、负号或小数点；补看实际触发帧。

录制、播放等操作共用同一道具时，分别检查点击前的按钮、操作中的图标和结果；手指接触正确不代表屏幕语义正确，不能用同一个默认播放状态代替所有操作。

写字或绘画要区分悬停、落纸、留下笔迹和抬笔，笔迹只在笔尖接触可写区域时出现。同一姿势复用于评分、规划或绘画时，分别检查结果的含义，不能沿用同一种笔迹。

常见层序是身体/远肢 → 桌面或操作物 → 近肢 → 持物 → 手指，但应按实际遮挡调整。屈肘托腮时近处前臂常需覆盖袖子；只把整条手臂画完后再画袖口，可能看起来拳头直接从肩部长出。

袖口、领口等开口须分清远缘、开口内的身体和近缘。若素材把内腔画成不透明色块，整件衣服压在皮肤前面会像挡在身前；共用骨架并不能修正遮挡。按实际边缘拆层或局部遮罩，使身体盖住后腔、近缘仍包住身体；遮罩跟随衣服同一变形。细小开口不能直接用粗网格整块切分，修后检查抬臂、持物、松手和放松姿势的近缘连续性、皮肤越界与透底缝。

持物前臂跨到胸前时，上臂和前臂可能需要分层绘制；若整臂仍放在躯干后，手会看似悬空。近景确认肩、肘、前臂、手与道具的连续轮廓，并检查进入和退出过程。

每次检查：

1. 接触前，手有合理的靠近路径和预备姿势。
2. 接触期间，手跟随对象；手指、杯柄、笔杆或页角之间没有滑脱、悬空或双重轮廓。
3. 释放后，物体有支撑或合理运动，手自然离开；不能手先消失、物体再跳到终点。落稳物体不再继承人物呼吸或手腕微动；持物与空手分别检查退出姿态，避免空手返回原握持位置。
4. 遮挡变化时肢体仍可解释，标签、脸和关键操作区域没有被无意盖住。

## 容易失败的动作

| 动作 | 必看关系 |
|---|---|
| 持手机→点击/思考→放下 | 持握手与前臂、触屏指尖、低肘托腮、屏幕可读、手机落桌和松手时刻 |
| 写字/评分 | 纸确实在桌面上；笔尖落在可写区；笔杆尾端与前臂方向可区分；腕、手、笔是一套姿势 |
| 翻页→放大镜 | 捏住页角并跟随翻页；松手后退出；工具再进入，避免两条前臂交叉遮断；放大对象含可读信息 |
| 开抽屉 | 手贴把手、抽屉沿同一方向移动；内容不从柜面漂浮穿出；空格的含义只作用于相应类别 |
| 行走 | 朝向与路径一致；髋膝踝在各相位合理；支撑脚相对地面不过度滑动；摆臂和步幅协调 |
| 多人换位/上台 | 人物身份和数量连续；实际移动区间的中间态不交叉穿人；脚底支撑随所属布局一致；固定镜头中点不一定落在动作中途 |
| 交谈/倾听 | 说话者和听者身份清楚；嘴、视线、手势与意图一致；桌面食物和静置手不相互穿过 |

多人布局变换应从真实触发时刻检查开始、行程中段、抵达及相邻切镜。叙事只需说明筛选前后布局时，可采用短切换；不必强行插值所有人的位置。选择淡出再淡入时，两套布局及其支撑面保持对应，避免同时叠成重复人物；未表现行走就不声称行走已完成。

同一动作跨景别使用同一时间轴；不能每个镜头把步态、页角或落物进度重置为零。拟音绑定可见接触事件，不能只依赖沿用的任意进度百分比。

双脚反解同时受髋部位置约束。迈步或身体平移后，应重新检查支撑脚是否仍在固定骨长的可达范围内；适当调整重心与髋部高度，不能靠截断目标或伸长腿掩盖误差。检查覆盖前后景各角色，步态中的抬脚、落脚与邻人脚位也要看实际画面。

行走先确定朝向、路径和景深：固定镜头、同一景深的左右移动保持人物大小；朝镜头走逐渐变大，远离镜头逐渐变小，斜向移动由实际深度决定比例。镜头推拉另算，不能把前后移动只做成屏幕平移或任意整体缩放。正面行走的膝盖主要向前屈曲，不能把抬脚反解为左右外撇；侧向行走需要相应朝向的素材和姿势，不能拿正面站姿横移冒充。

行走要先检查完整人体的承重与节奏：重心随支撑脚转换，骨盆与肩部适度反向转动，手臂与对侧腿配合，肘、腕随摆动方向连续变化，头部相对稳定；起步、落脚和收步有连续的速度与缓冲。不能只给双腿循环，再让僵直的上身整体平移；也不能给每个部位叠加无关的正弦摇摆。收到“不协调”的反馈时，先做原速、固定镜头、不中途裁掉头肩的全身短样，覆盖起步到停稳；脚部特写与骨长断言不能替代全身自然度检查。

正面步行不能只确认代码里有摆臂：把肩、肘、腕的最终屏幕轨迹与整体位移、景深缩放分开看，确认相对身体的轮廓变化可读。深度里的小幅转动可能在正面几乎看不见；修复前取得与视角相关的真人步行视频，观察前手屈肘靠近髋前、后手回到髋旁及落脚时的反转关系。侧面参考有助于辨认前后摆动，但不能直接当成正面幅度依据；抽帧也不能冒充原速观看或精确动作捕捉。

摆臂转折由实际落脚、换重与收步事件驱动，不用身体总路程进度代替步态相位。去除不自然的整体晃动或下蹲曲线时，同步检查髋部与双脚的可达范围；不能以伸长腿或放宽误差掩盖支撑问题。前臂靠近衣身后若出现折叠，先查原画透明间隙、权重边界及网格跨缝关系，再决定是否需要分层，保留可见三角形与近景检查。

同一场景的人物和参照物共用地面、视平线与尺度关系。先确定合理的身高比例，再从深度推导画面大小，不能让主角按一套透视缩放、配角按行号另定高度。沿移动路径检查经过参照物前、脚下平齐时和经过后的完整人物，比较脚底、头部、肩线与遮挡；插画背景还须目视核对门、桌椅和花箱的实际支撑区域，投影公式正确不能证明人物没有站在道具上。

远近变化同时作用于身体、脚、落地阴影与遮挡次序，并与地面透视一致。支撑脚在地面的接触点保持固定，摆动脚抬起后再落地；普通行走应始终至少有一只脚承重。检查实际鞋底而非仅踝关节坐标，核对近远两端及整个步态周期，避免模型整体漂移、缩放造成滑步，或身体升高、阴影脱离使人物像在飞。

坐姿、站姿和卧姿分别设计支撑锚点；卧姿可用头枕接触点定位，不能靠旋转坐姿冒充躺下。只切到站稳结果时，交付说明不能声称已经表现完整起身或行走。

## 怎么判断修好了

先判断动作是否表达原定行为、运动机制是否可信，再在成片尺寸看完整人体比例和轮廓，在近景看接触，在连续序列看速度、肢体投影变化和衔接。几何断言验证有限值、关节可达、接触偏差和状态边界；视觉审查验证行为、协调性、自然性与层级；两者互不替代。“没有穿透”“手没断、物没掉”都不是人物动作合理的充分证据，缩小幅度也不能修复错误的驱动方式。

同类缺陷反复修仍失败时，先定位结构原因：错误视角、层顺序、手的重复所有权、不可达姿势、过度共用变体。改变摆位、动作拆分或表示方式，做小样验证，不继续盲目微调关节数值或重渲整片。全身联动不是给每个部位增加运动；收到身体反复晃动的反馈时，先在同一镜头分别核对头、胸、骨盆的上下与左右轨迹，并区分周期性颠动、前进透视和镜头移动，不能默认“晃动”就是左右摆。逐步反算支撑高度也可能把身体画成反复蹲起；稳定身体高度后还须验证腿的可达范围、实际轮廓和落地，不能靠拉长腿掩盖。修复集中于已定位的轴和驱动，不同时改变场景尺度和构图。只有骨长、接触和抽帧证据时不能把新短样提升为修复成功的整片交付；用户明确否定的版本标为失败，原版保留作对照。

修复共享人物函数后，复查所有使用该姿势的场景、镜像版本、近景、过渡端点和切点；只看一个“最好看”的中间姿势不能关闭问题。

## 人物动作放行

这是含可见人物动作的制作门槛，不以检查图数量代替实际判断。

1. **原画与绑定姿势。** 在原尺寸和实际最大景别按上述身体链条核对完整结构；逐个角色分别记录人物左手、右手连接的前臂、掌背与拇指/四指证据，不用“解剖正常”一词代替。核对头颈、肩胯、双腿与脚部支撑，按原画真实关节绑定。若出现同侧双手、肘膝反折、掌腕不相容、缺肢/多肢或比例突变，先修原画/绑定，不靠遮罩或缩小景别隐藏。完整原画本身也须检查，不自动认定解剖正确。
2. **实际动作范围。** 用正式场景、道具和镜头尺度验证静止、靠近、接触、最大伸展、松手及收回，覆盖每个角色和左右/镜像变体。逐帧使用场景真实状态组合，不能把单独前伸、单独抬手的测试代替“伸到终点再抬手、抬手收回”；结尾或另一镜头新增的动作组合也须单独验证，不继承推物动作的适用范围。连续播放或逐帧密集序列须实际查看；远景看全链条，近景看肘内外弧、腕口与指物接触。原速节奏与密集静帧结果分别记录。
3. **几何拦截。** 蒙皮检查实际不透明区域的三角形朝向与塌陷，固定骨长之外还核对肘支、手腕角度、接触误差和释放后漂移。骨长不变、有限顶点、平滑轨迹、手数量常量都不能证明解剖或接触成立；抽象测试姿势不能替代本片真实轨迹。
4. **行为与运动机制。** 单独给出动作意图、实际可见的驱动关系、作用方向和结果判断，指出样片中的具体相位与时码；不能拿前三项的通过替代。检查完整往复周期、方向反转及实际使用景别，不用静止持物姿态或互不关联的周期摇摆证明功能动作成立。
5. **原速自然度。** 实际以1倍速观看完整动作短样，记录具体文件、所看范围、观察者，以及预备/发力/回落、重心与支撑、头身配合、加减速、停顿和反转的判断；不要求无关部位都动。密集静帧用于定位结构与接缝，不能替代速度感和表演判断。播放器开过、文件能播放、生成过GIF或已有抽帧均不算原速审看。工具不能真实观看时保持未通过，只交付局部短样，不导出任何名义的整片；用户对该版本该动作的明确观看反馈可作为证据，不能推断接受。
6. **版本绑定后放行。** 在现有QA中绑定原画、角色/场景代码与实际编码样片，分别记录完整结构、左右身份、行为机制、接触、遮挡、连续性和自然度。使用 `requireMotionReview` 时须有 `handedness`、`action_mechanics`、`naturalness` 等独立项；自然度还须注明 `method: real_time_playback` 与所看MP4的 `artifact_path`。这些字段只记录审查，不自动判断图像。缺项、失败、证据不足或输入变更均只允许修复样片；不能自动填true或以“候选”名义绕过。用户再次指出基础结构错误时，用实际原画和编码样片做独立结构审查，不向审查者提供旧通过结论。

用户否定的人物版本标为失败，撤销相应通过结论并保留对照。发现结构性变形后先停批量导出，定位原画姿势、骨架、蒙皮或接触状态的根因；同类局部补洞仍失败时改表示方法。修复完成后以本片实际动作的证据放行，下一期换人、换素材、换动作或换景别仍重新验证，不能继承上一期的“已通过”。
